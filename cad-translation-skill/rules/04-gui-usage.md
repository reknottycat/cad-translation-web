## GUI使用规则

### 启动方式

```bash
python gui.py
```

### 操作流程

1. **选择文件**: 点击"选择DWG文件"或"选择文件夹"
2. **转换DWG**: 点击"1️⃣ 转换DWG至dxf"
3. **提取文本**: 点击"2️⃣ 提取文本"
4. **编辑翻译**: 点击"📊 打开Excel"
5. **应用翻译**: 点击"3️⃣ 应用翻译"
6. **一键处理**: 点击"🚀 一键处理"完成全流程

### 配置选项

- 字体选择
- 字体大小缩放
- 翻译模式设置
