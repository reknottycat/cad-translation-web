PIPELINE / 处理流水线

不是截图翻译，
是图纸结构内的语言替换。

系统直接处理 CAD 文字实体。每个阶段都有明确产物，既能一键贯通，也能通过 Excel 或 CLI 分步检查、修订与恢复。

  1. 01

    转换

    将 DWG 规范化为可处理的 DXF；支持厂商 CAD COM、ODA、LibreDWG 等后端。

    DWG → DXF
  2. 02

    提取

    识别 TEXT / MTEXT 实体，导出可审核的 Excel，同时记录实体定位信息。

    DXF → XLSX
  3. 03
    文A

    翻译

    通过 LLM 批量翻译，结合术语表、缓存、智能过滤与失败重试控制质量和成本。

    ZH → TARGET
  4. 04

    回填

    按实体地址写回译文，可选择替换、追加或换行模式，生成新的 DXF 文件。

    XLSX → DXF
