# CAD 审计修复与验收记录

本记录对应 2026-09-05 审计后的修复，规范产品版本为 `2.1.0`。原始问题和基线证据保留在 [审计快照](AUDIT_2026-09-05.md)；当前模块与行为以 [架构说明](ARCHITECTURE.md) 和 API 文档为准。

## 修复结果

| 审计范围 | 交付行为 |
|---|---|
| M1：配置加载与认证 | 工作台分别处理配置、预设和语言加载；认证失败可识别、可重试；请求及文件下载统一携带实例令牌。 |
| M2/M3：凭据契约 | 常规保存省略凭据即保留；替换和显式删除分开处理；摘要只返回配置状态与掩码。 |
| M4/M5：模型配置一致性 | 工作台成为配置入口；服务商独立 profile、协议和有序备用模型可编辑并持久化；Custom 不继承其他服务商参数。 |
| M6：自定义服务商 | Unicode 显示名与稳定 ID 分离，拒绝覆盖内置 ID 和重复新增。 |
| LLM 探测与限流 | 探测等待移出锁；并发调用合并探测；配额为等待者逐个预订；取消停止提交新 chunk 和后续重试。 |
| LLM 协议与传输 | JSON 缺项、空值和类型错误不能冒充成功；阻塞网络工作移到线程；显式关闭系统代理覆盖 ALL_PROXY。 |
| CAD 注册和执行 | 先保存输入、短锁登记；重型转换和提取只持任务锁；后台上传返回 202；有界工作池为 2 个执行线程、18 个总容量槽。 |
| 恢复与取消 | 每任务唯一执行权，重复执行返回 409；启动识别失去执行者的任务；断点补齐未译记录，继承原语言与排版，改语言须重启任务。 |
| 实体回填 | 记录 ID 对应实体句柄，同文不同译可分别写入 DXF 和 Excel；旧格式中相互冲突的译文会被拒绝。 |
| 历史与产物 | JSON 为权威记录，SQLite 摘要索引用 SQL 分页；删除后迟到写入不复活任务；下载与 ZIP 使用受锁保护的快照。 |
| R1/R2：EXE 生命周期 | payload 哈希标识代码缓存；用户数据库、任务和配置独立持久化；互斥解压和完整标记防止复用半成品。 |
| R3/R5：发布装配 | 本地、云端和源码包共用过滤/脱敏规则；工具清单按实物计算；递归归档审计、版本一致性和两次 EXE 启动验收进入构建门禁。 |
| R4：访问边界 | 静态产物与旧翻译入口接受相同 Admin Guard；开启但缺令牌配置时继续 fail-closed。 |
| 旧项目接口 | 统一调用可信 CAD 实现；持久化任务后派发；修复异步契约、内容哈希去重、项目物理产物清理及汇总状态。 |
| 模块边界 | 拆分工作台、LLM 与任务服务；本次改动的源码模块均不超过 800 行。 |

## 性能证据

条件、复现命令和各轮原始采样见 [性能验证](CAD_PERFORMANCE_VALIDATION.md)。合成 10000 条历史的常规末页从约 3.118 秒降到约 0.006 秒；首次旧 manifest 导入约 9.98 秒，重启签名校验约 1.48 秒。导入和启动成本仍随历史量增加。

相同 0.1 秒模拟网络延迟下，两个并发连接探测约 0.101 秒完成且只发起一次探测；配额预订得到 `[0, 1, 2, 3]` 秒。合成 DXF 的两线程结果没有证明增加并发会更快，因此维持有界执行器。
