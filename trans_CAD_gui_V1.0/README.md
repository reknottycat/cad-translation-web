# CAD文件翻译处理系统使用说明

## 系统简介

CAD文件翻译处理系统是一个专为CAD文件（DWG/DXF）设计的翻译工具，支持从CAD文件中提取文本，通过Excel进行翻译，然后将翻译结果回填到CAD文件中。

## 功能特性

- ✅ DWG文件转换为DXF格式（使用AutoCAD COM接口）
- ✅ 从DXF文件中提取文本到Excel表格
- ✅ 支持在Excel中编辑翻译
- ✅ 将翻译结果回填到DXF文件
- ✅ 支持多种翻译模式（替换原文/在下方添加翻译）
- ✅ 可自定义字体和字号
- ✅ 线程安全设计，支持取消操作
- ✅ 详细的日志记录

## 系统要求

### 硬件要求
- 处理器：Intel i3 或更高
- 内存：4GB 或更高
- 存储空间：100MB 或更多

### 软件要求
- Windows 10/11 操作系统
- Python 3.8 或更高版本
- CAD软件（二选一）：
  - AutoCAD 2016 或更高版本（默认使用）
  - 浩辰CAD（GStarCAD）或中望CAD（ZWCAD）
- Microsoft Excel（用于编辑翻译）

## 安装与运行

### 方法一：直接运行（推荐）

1. 确保已安装 Python 3.8 或更高版本
2. 双击 `start_gui.bat` 脚本
3. 脚本会自动检查并安装必要的依赖项
4. 等待应用启动完成

### 方法二：手动安装依赖

1. 打开命令提示符，进入本文件夹
2. 运行以下命令安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行GUI应用：
   ```bash
   python gui.py
   ```

## 使用步骤

### 基本流程

1. **选择文件或文件夹**
   - 点击"选择DWG文件"按钮选择一个或多个DWG文件
   - 或点击"选择工作文件夹"按钮选择包含DWG/DXF文件的文件夹

2. **转换DWG至DXF**（如果需要）
   - 点击"1️⃣ 转换DWG至dxf"按钮
   - 系统会自动连接AutoCAD并转换所有DWG文件
   - 转换后的DXF文件会保存在 `converted_dxf` 文件夹中

3. **提取文本**
   - 点击"2️⃣ 提取文本"按钮
   - 系统会从DXF文件中提取文本并生成 `extracted_texts.xlsx` 文件

4. **编辑翻译**
   - 点击"3️⃣ 打开翻译表"按钮
   - 在Excel中填写 `translation` 列的翻译内容
   - 保存Excel文件

5. **应用翻译**
   - 点击"4️⃣ 应用翻译"按钮
   - 系统会将翻译结果回填到DXF文件中

### 一键处理

- 点击"🚀 一键处理"按钮可自动完成：
  1. 转换DWG至DXF
  2. 提取文本
  3. 打开翻译表

## 配置选项

### 翻译模式
- **在下方添加翻译**：保留原文，在下方添加翻译文本
- **替换原文**：用翻译文本替换原文

### 字体设置
- **字体**：选择翻译文本使用的字体
- **字号减少**：设置翻译文本的字号相对于原文的减少值

## 常见问题

### 1. 无法连接到AutoCAD
- 确保AutoCAD已安装并启动
- 确保AutoCAD版本为2016或更高
- 尝试以管理员身份运行应用

### 2. 提取文本失败
- 确保DXF文件格式正确
- 检查是否安装了ezdxf库
- 查看日志获取详细错误信息

### 3. 回填翻译失败
- 确保Excel文件已保存
- 确保Excel文件格式正确
- 检查是否安装了pandas和openpyxl库

### 4. 应用启动失败
- 确保已安装Python 3.8或更高版本
- 运行 `start_gui.bat` 自动安装依赖
- 查看命令提示符中的错误信息

## 注意事项

- 本工具仅支持DXF文件的文本提取和回填
- DWG文件需要通过CAD软件转换为DXF格式
- 转换过程中请保持CAD软件处于打开状态
- 大型CAD文件可能需要较长的处理时间
- 建议在处理前备份原始CAD文件

## 使用浩辰CAD转换器

如果您使用的是浩辰CAD（GStarCAD）或中望CAD（ZWCAD），可以按照以下步骤切换到浩辰转换器：

1. 打开 `gui.py` 文件
2. 找到第525-545行的导入代码
3. 注释掉 `AutoCADConverter` 的导入代码
4. 取消注释 `OptimizedHaoChenCADConverter` 的导入代码
5. 找到第564行的实例化代码
6. 将 `converter = AutoCADConverter()` 改为 `converter = OptimizedHaoChenCADConverter()`

浩辰转换器针对浩辰CAD和中望CAD进行了优化，可能会提供更好的性能和兼容性。
